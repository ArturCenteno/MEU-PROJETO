# ECHO-PULSE: PAINEL DE MONITORAMENTO CLIMÁTICO

- o projeto consiste em uma interface que exibe as principais informações climáticas de acordo com a região do usuário.
- ele acessa sua localização para obter dados em tempo real.
- o projeto terá acesso à bancos de dados meteorológicos.
- ele monitora o clima, temperatura, previsão do tempo e alerta de possíveis eventos climáticos como tempestades e enchentes.
- ele também deve fornecer instruções e orientações sobre o que fazer em alguma circunstância.
- por se tratar de um protótipo, ele não utilizará necessariamente os dados mais precisos, mas deve apresentar uma interface funcional que pode ser reutilizada.
